# HU14 Historial completo de reservas

La pantalla administrativa existente conserva calendario, estadísticas y ranking. La consulta protegida `/admin/reservas/amenidades` ahora incluye cancelaciones y admite filtros combinables `from`, `to`, `id_usuario`, `id_amenidad`, `unidad` y `estado`. La tabla mantiene usuario, unidad, amenidad, fecha, horario y estado.
